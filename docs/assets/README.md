# Assets

This directory contains visual assets for the README and documentation.

## Required Assets

| File       | Description              | Dimensions |
| ---------- | ------------------------ | ---------- |
| `logo.svg` | Project logo             | 80x80      |
| `demo.png` | Main demo screenshot/GIF | 800px wide |

## Optional Assets (for enhanced README)

| File                | Description                   |
| ------------------- | ----------------------------- |
| `canvas.png`        | Analysis Canvas screenshot    |
| `evidence.png`      | Evidence Dashboard screenshot |
| `insights.png`      | Insight Board screenshot      |
| `transcription.png` | Transcription in progress     |

## Guidelines

- Use dark theme screenshots to match the product aesthetic
- Optimize images for web (compress PNGs, use SVG where possible)
- Demo GIF should be under 5MB for fast loading
